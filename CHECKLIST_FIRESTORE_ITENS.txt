1. Criação da Tabela de Itens no Banco de Dados

Criamos documento passo a passo detalhado para configuração do Firestore no console do Firebase.
Configuramos Firestore Database no projeto Firebase com modo de produção.
Definimos localização do banco de dados (southamerica-east1 para Brasil).
Criamos coleção 'itens' no Firestore para armazenar os dados dos itens.
Configuramos regras de segurança do Firestore permitindo leitura e escrita apenas para usuários autenticados.
Estrutura da coleção definida com campos: nome (string), categoria (string), unidadeMedida (string).
Valores permitidos para unidadeMedida: kg, unidade, litro, caixa, pacote, lata, bandeja.
Documento criado com ID automático gerado pelo Firestore.

✔️ Benefícios:
Banco de dados NoSQL escalável e gerenciado pelo Firebase.
Estrutura de dados organizada e consistente.
Segurança garantida com regras de autenticação.
ID automático elimina necessidade de gerenciar chaves primárias manualmente.

2. Integração da Tela Itens com o Backend

Adicionamos getFirestore ao firebase.ts e exportamos instância db para uso na aplicação.
Criamos serviço itensService.ts com funções CRUD completas para interação com Firestore.
Implementamos getItens() para buscar todos os itens ordenados por nome.
Implementamos addItem() para adicionar novos itens ao Firestore.
Implementamos updateItem() para atualizar itens existentes.
Implementamos deleteItem() para remover itens do banco.
Criamos subscribeItens() com listener em tempo real usando onSnapshot do Firestore.
Atualizamos AppContext.tsx removendo localStorage para itens e implementando sincronização com Firestore.
Substituímos funções síncronas por assíncronas (addItem, updateItem, deleteItem) no contexto.
Implementamos listener em tempo real que atualiza estado automaticamente quando dados mudam no Firestore.
Atualizamos componente Insumos.tsx para trabalhar com operações assíncronas.
Adicionamos estados de loading e error para feedback ao usuário durante operações.
Implementamos tratamento de erros com mensagens em português.
Adicionamos confirmação antes de excluir itens para prevenir exclusões acidentais.
Implementamos desabilitação de campos e botões durante operações para melhor UX.
Adicionamos estilos CSS para botões desabilitados e mensagens de erro.
Invertemos ordem dos botões no formulário (Cancelar à esquerda, Salvar/Cadastrar à direita).

✔️ Benefícios:
Sincronização em tempo real entre múltiplos usuários e dispositivos.
Dados persistidos no servidor garantindo segurança e backup automático.
Experiência do usuário melhorada com feedback visual durante operações.
Código organizado com separação de responsabilidades (service layer).
Escalabilidade garantida pelo Firebase sem necessidade de gerenciar servidor próprio.
